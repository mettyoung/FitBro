## Codebase Patterns
- **Gradle env**: JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk-21.jdk/Contents/Home; run UNSANDBOXED. Typecheck = `:composeApp:compileDebugKotlinAndroid` + `:composeApp:compileKotlinIosSimulatorArm64`. No browser test on this KMP app.
- **SQLDelight schema version**: current highest migration = 4.sqm → next migration = 5.sqm. Place in `composeApp/src/commonMain/sqldelight/com/mettyoung/fitbro/data/db/migrations/`.
- **SQLDelight .sq files**: live in `composeApp/src/commonMain/sqldelight/com/mettyoung/fitbro/data/db/`. Each .sq file = one entity. Queries return generated types; use `.asFlow().mapToList(Dispatchers.Default)` for Flow, `withContext(Dispatchers.Default)` for suspend ops.
- **StateHolder pattern**: `DashboardStateHolder.kt` / `FoodDiaryStateHolder.kt` — receives repo + CoroutineScope; exposes `StateFlow<UiState>`; launches coroutines in `scope.launch {}`. Wired in `App.kt` via `remember { ... }`.
- **App.kt wiring**: data sources instantiated first, then repos, then StateHolders, all via `remember {}` blocks. Pass StateHolder down to composable.
- **Tab wiring**: `DashboardWithTabs` in `DashboardScreen.kt` — uses `TabRow` + `when(selectedTab)`. Add new tab enum value and new `when` branch.
- **Colors** (`ui/Theme.kt`): MiOrange 0xFFFF6B00, MiTextSecondary 0xFF6C757D, ColorProtein 0xFF4361EE, ColorCarbs 0xFFF72585, ColorFat 0xFF4CC9F0.
- **Date util**: `todayString()` returns today as "YYYY-MM-DD". `kotlinx.datetime` available in commonMain — use `Clock.System.todayIn(TimeZone.currentSystemDefault())` for LocalDate; `LocalDate.parse(str)` for formatting day labels.
- **Domain models**: `data/model/` — plain data classes. Keep fields nullable where DB column is nullable.
- **ModalBottomSheet**: used in `CustomFoodManagerSheet.kt` — reuse that pattern for the cardio log dialog.
- **DatePickerDialog**: already exists in codebase — locate and reuse rather than writing from scratch.
