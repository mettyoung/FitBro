## Macro Food Diary Notes
- SQLDelight 2.x for KMP: app.cash.sqldelight android-driver + native-driver + coroutines-extensions
- OpenFoodFacts endpoint: https://world.openfoodfacts.org/cgi/search.pl?search_terms={query}&action=process&json=1&page_size=20
- User-Agent required: FitBro/1.0 (Android; emmettyoung92@gmail.com)
- Macro calc: macroG = (macroPer100g * servingG) / 100.0, round to 1 decimal
- oz conversion: 1 oz = 28.3495g
- "1 serving" unit: use result.servingSizeG; if null hide option and default to 100g
- Diary DB = source of truth; HC-read DailyIntake fallback only when diary total is empty for date
- DashboardStateHolder owns selectedDate shared between Balance and Macros tabs
- Day-of-week from date string: Zeller's congruence; h=0→Sat, h=1→Sun, h=2→Mon, h=3→Tue, h=4→Wed, h=5→Thu, h=6→Fri
- String.format() NOT available in KMP commonMain — use manual arithmetic
- No kotlinx-datetime — use DateUtil.kt
- HealthConnect NutritionRecord write: fire-and-forget, iOS no-op
- State holders in com.mettyoung.fitbro.ui.{feature}, take CoroutineScope constructor param
- Gradle typecheck: :composeApp:compileDebugKotlinAndroid (Android) + :composeApp:compileKotlinIosSimulatorArm64 (iOS)
- Dispatchers.IO not available in K/N commonMain — use Dispatchers.Default for SQLDelight mapToList/withContext
- HC alpha12: Metadata constructor is `internal` — writeNutritionRecord is no-op on Android (same as iOS) until HC stable
- HC alpha12: NutritionRecord.MEAL_TYPE_* constants don't exist on companion — use integer literals (0=unknown,1=breakfast,2=lunch,3=dinner,4=snack) when HC write becomes available
- SQLDelight mapToOne() on aggregate query with COALESCE: generated type may have nullable Double fields — handle with ?: 0.0 in mapper
- Metadata name collides with kotlin.Metadata annotation — import HC Metadata with alias: `import ... as HcMetadata`
