## TEF Macro Notes
- TEF formula: (proteinG * 4 * 0.25) + (carbG * 4 * 0.08) + (fatG * 9 * 0.03)
- Fallback when all macros = 0.0: totalCalories * 0.10
- DailyIntake macro fields: proteinG, carbG, fatG (grams, not kcal)
- Health Connect macro metrics: NutritionRecord.PROTEIN_TOTAL, NutritionRecord.TOTAL_CARBOHYDRATE, NutritionRecord.TOTAL_FAT
- HealthKit macro identifiers: HKQuantityTypeIdentifierDietaryProtein, HKQuantityTypeIdentifierDietaryCarbohydrates, HKQuantityTypeIdentifierDietaryFatTotal
- Both HC and HK: unit is grams for all three macros

## Codebase Patterns
- multiplatform-settings 1.3.0: Android actual uses `SharedPreferencesSettings(prefs)` from `com.russhwolf.settings.SharedPreferencesSettings`; iOS actual uses `NSUserDefaultsSettings(NSUserDefaults.standardUserDefaults)` from `com.russhwolf.settings.NSUserDefaultsSettings`. Both in same artifact `com.russhwolf:multiplatform-settings` added to commonMain.
- Cache keys follow pattern `{type}_{startDate}_{endDate}` for date-range lookups; sync timestamps use `sync_{CacheSource.name}` as keys.
- K/N 2.3.21 ObjC category methods need EXPLICIT imports to be accessible on class companions.
- Use `NSCalendar(calendarIdentifier = NSCalendarIdentifierGregorian)` — `NSCalendar.currentCalendar` and `NSCalendar.current` are NOT accessible in K/N 2.3.21.
- Health data package: `com.mettyoung.fitbro.data.health` for HealthKit/HealthConnect; `HealthResult<T>` + `HealthDataError` sealed classes.
- iOS cinterop: never use `is CFStringRef` (erased type) in when expressions — use `is CPointer<*>` instead.
- Gradle typecheck: use :composeApp:compileDebugKotlinAndroid (Android) and :composeApp:compileKotlinIosSimulatorArm64 (iOS).
- Data layer package: `com.mettyoung.fitbro.data.model` for domain models.
- `currentEpochMs()` expect/actual in `com.mettyoung.fitbro.util` — use for all timestamp needs in common.
- UI state holders live in `com.mettyoung.fitbro.ui.{feature}`; take CoroutineScope as constructor param.
- No kotlinx-datetime in project — use DateUtil.kt (manual arithmetic).
- Day-of-week from "YYYY-MM-DD" string: use Zeller's congruence; h=0→Sat, h=1→Sun, h=2→Mon, h=3→Tue, h=4→Wed, h=5→Thu, h=6→Fri.
- `String.format()` NOT available in KMP commonMain — use manual arithmetic for number formatting.
- Health Connect alpha12: `PermissionController.createRequestPermissionResultContract()` is static companion method.
- `HealthConnectClient.getSdkStatus(context) == SDK_AVAILABLE` check before calling `getOrCreate()`.
- DashboardStateHolder uses HealthDataSource for all data fetching; TEF computed as 10% of intake.
- CalorieMathRepositoryImpl in `data/repository/` — takes nullable ActivityBurn param.
- `String.minusDays()` is top-level extension in `com.mettyoung.fitbro.util` — import explicitly.
- `String.format()` NOT available in KMP commonMain (JVM-only); use manual arithmetic.
- CalorieBalanceChart.kt at: composeApp/src/commonMain/kotlin/com/mettyoung/fitbro/ui/dashboard/CalorieBalanceChart.kt — currently Canvas-based horizontal bar chart. This PRD replaces it with LazyColumn 7-day windows.
- DailyBalance model: date: String, intake: Double, burn: Double, balance: Double, bmr: Double, tef: Double, neat: Double, eat: Double.
- HorizontalDivider (not deprecated Divider) for Material3 dividers in commonMain.
