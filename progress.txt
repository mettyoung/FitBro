Learnings:
- SQLDelight: two tables in one .sq file → all queries under `<fileName>Queries`. `MacroGoalProfile.sq` → `database.macroGoalProfileQueries` covers `WeekdayGoalMapping` queries too.
- `getActiveProfileForDate` waterfall: mapping row → profile by id → Default profile by name → first profile → in-memory fallback from UserSettingsDataSource.
- `seedDefaultIfEmpty()` is NOT in the `MacroGoalRepository` interface; it's a concrete method on impl, called from App.kt.
- SQLite INTEGER PRIMARY KEY without AUTOINCREMENT = rowid alias. WeekdayGoalMapping.weekday is PK so INSERT OR REPLACE handles upsert cleanly.
